# دوايا | Dawaya

واجهة تجريبية عربية لمشروع يتابع بلاغات الأدوية الناقصة وتقارير التوفر حسب المنطقة. هدف هذه المرحلة عرض الفكرة وتجربة شكل الموقع قبل بناء الـBackend وقاعدة البيانات.

> **تنبيه:** بيانات الأدوية والصيدليات في نموذج الواجهة توضيحية فقط، ولا تمثل التوفر الفعلي للأدوية.

## الملفات الحالية

- `index.html` — نموذج واجهة دوايا والبحث التجريبي.
- `portfolio.html` — تعريف المشروع والفريق وتقسيم العرض. يمكن إضافة صورة وتعديل وصف الأعضاء محليًا من الصفحة.
- `Dawaya_Project_Overview_Arabic_محدث.docx` — وثيقة نطاق المشروع والميزات والبنية المقترحة.
- `Dawaya_Project_Overview_Arabic_محدث.pdf` — نسخة PDF من الوثيقة.

## التشغيل الآن

لا يحتاج النموذج الحالي إلى تثبيت حزم:

1. نزّل أو استنسخ المستودع.
2. افتح `index.html` في المتصفح لعرض نموذج دوايا.
3. افتح `portfolio.html` لصفحة الفريق.

الصور والأوصاف التي تُضاف من صفحة البورتفوليو محفوظة في تخزين المتصفح الحالي فقط؛ يلزم تضمين الصور ضمن ملفات المشروع لنشرها مع الموقع.

## ما لم يُنفذ بعد

هذا الإصدار واجهة ثابتة للتجربة. لا يحتوي حاليًا على API أو خادم Node.js/Express أو PostgreSQL. هذه أجزاء مخططة للتنفيذ على مراحل، ويجب ألا تُعرض بيانات النموذج كبيانات مخزون فعلية.

## التقنيات المخطط لها

React وTypeScript للواجهة، Node.js وExpress لخادم REST API، PostgreSQL وSQL migrations لقاعدة البيانات، وGit/GitHub لتوثيق التغييرات.

## توثيق كل خطوة باستخدام Git

بعد إنجاز تغيير مفهوم ومراجعته:

```bash
git status
git diff
git add index.html
# استبدل اسم الملف بالملف/الملفات التي عدّلتها
git commit -m "feat: describe the change"
git push
```

لا يلتقط Git كل ضغطة مفتاح تلقائيًا؛ كل `commit` لقطة موثقة لحالة الملفات وقتها. لا ترفع كلمات مرور أو ملفات `.env`.
